# Changelog

All notable user-visible changes to the Langflow TOS application package.

## 1.9.3-1 — 2026-11-12

### Added
- First release. Langflow (`langflowai/langflow:1.9.3`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8114 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/langflowdocker/`.
